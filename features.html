Every tool your backend needs

From database to auth to edge functions — Nexora handles the infrastructure so you can focus on your product.

Database

Postgres. Fully managed.

Every Nexora project runs on a dedicated Postgres instance. Get auto-generated REST and GraphQL APIs, row-level security, custom functions, and support for every extension.

PostgreSQL 16 Row-Level Security pgvector PostGIS GraphQL REST API
-- Row-level security example
CREATE POLICY "users_own_data"
  ON profiles
  FOR ALL
  USING (auth.uid() = user_id);

-- Auto-generated REST call
GET /rest/v1/profiles
  ?select=id,name,avatar_url
  &user_id=eq.auth.uid()

-- Or use the client
const { data } = await nexora
  .from('profiles')
  .select('*')
🔐
Authentication

Auth that just works.

Add authentication in minutes. Support for email, magic links, phone, and 20+ OAuth providers out of the box. Multi-factor auth, session management, and SAML SSO for teams.

Email + Magic Link Google / GitHub MFA / TOTP SAML SSO JWT Sessions
// Sign up with email
const { data, error } = await
  nexora.auth.signUp({
    email: '[email protected]',
    password: 'super-secure'
  })

// OAuth with Google
await nexora.auth.signInWithOAuth({
  provider: 'google',
  options: { redirectTo: '/dashboard' }
})

// Get current user
const { data: { user } } =
  await nexora.auth.getUser()

Edge Functions

Serverless at the edge.

Deploy TypeScript functions to 18 global regions. Sub-5ms cold starts, Deno runtime, native Nexora client access, and first-class support for webhooks and scheduled jobs.

Deno Runtime TypeScript 18 regions Cron Jobs Webhooks
// functions/send-welcome.ts
import { serve } from 'https://deno.land/std/http/server.ts'

serve(async (req) => {
  const { email } = await req.json()

  await sendEmail({
    to: email,
    subject: 'Welcome to our app!',
    html: welcomeTemplate(email)
  })

  return new Response('OK')
})

Realtime

Live data, everywhere.

Listen to database changes in real time. Broadcast messages to channels. Track user presence. Build collaborative apps, live dashboards, and notifications — zero polling needed.

WebSockets DB Change Streams Presence Broadcast
// Subscribe to DB changes
const channel = nexora
  .channel('messages')
  .on('postgres_changes', {
    event: 'INSERT',
    schema: 'public',
    table: 'messages'
  }, (payload) => {
    addMessage(payload.new)
  })
  .subscribe()
