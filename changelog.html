v2.0.0 Major April 10, 2025
New features
Real-time engine v2 — Rebuilt Elixir-based realtime server with 10× throughput, sub-100ms delivery globally, and support for up to 500k concurrent connections per project.
pgvector support — Native vector embedding storage and similarity search. Use VECTOR(1536) columns with IVFFlat or HNSW indexes.
New dashboard (Studio) — Completely redesigned interface with dark mode, inline SQL editor, and a visual schema editor.
Branching (beta) — Create database branches for staging/preview environments. Each branch is an isolated Postgres instance synced from main.
Edge Functions logs UI — Real-time function logs with filtering, search, and export from the dashboard.
Performance
Connection pooling — pgBouncer updated to 1.22 with improved transaction mode defaults. Connection limits increased across all plans.
Storage CDN — New CDN layer with 18-region PoPs. Average TTFB for file downloads improved from 240ms to 38ms.
Bug fixes
Fixed an issue where realtime subscriptions would silently drop after 30 minutes under certain network conditions.
Auth: Fixed magic link expiry not being respected on mobile Safari.
Storage: Fixed CORS headers not propagating correctly on transformation endpoint.
Breaking changes
Realtime channel API — .on('*', ...) wildcard subscriptions are deprecated. Use specific event types (INSERT, UPDATE, DELETE). Migration guide →
v1.9.4 Patch March 12, 2025
Bug fixes
Fixed session token refresh race condition that caused intermittent 401 errors on mobile clients.
Edge Functions: Fixed environment variable injection for projects with more than 50 secrets.
Database: Fixed slow query on auth.users when filtering by email without an index.
v1.8.0 Minor February 18, 2025
New features
MFA (TOTP) — Multi-factor authentication via authenticator apps is now available on all paid plans.
Storage transformations — Resize, crop, and convert images on-the-fly via URL params. Powered by libvips at the edge.
PostgREST 11 — Upgraded to PostgREST 11 with support for aggregate functions and improved OpenAPI spec output.
Performance
Auth token verification latency reduced by 40% with in-memory JWKS cache.
v1.7.2 Patch January 30, 2025
Bug fixes
Fixed OAuth state parameter not being validated correctly on GitHub OAuth flow.
Realtime: Fixed presence state not clearing after unexpected disconnects.
v1.6.0 Minor January 8, 2025
New features
Cron jobs — Schedule Edge Functions on a cron schedule directly from the dashboard or CLI.
Read replicas (Team+) — Automatic read replica provisioning in a second region for reduced read latency.
